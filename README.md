# Join fullsend-playground

Want to try fullsend agents? Click the link below to get an instant invite to this org.

## **[Click here to join](../../issues/new?title=Please+invite+me!&body=Just+click+%22Submit+new+issue%22+below+—+you%27ll+get+an+automatic+invite+within+seconds.)**

After you accept the invite, you'll have write access on the demo repos below (enough to run fullsend slash commands). Org-wide access stays read-only.

- **[go-hello](https://github.com/fullsend-playground/go-hello/issues)** — a Go HTTP service
- **[python-app](https://github.com/fullsend-playground/python-app/issues)** — a Python Flask API
- **[node-api](https://github.com/fullsend-playground/node-api/issues)** — a Node.js API

Create an issue, then comment `/fs-triage` or `/fs-code` to see the agents in action!
